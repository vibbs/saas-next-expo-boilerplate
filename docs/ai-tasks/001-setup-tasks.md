Below is a **phase-by-phase backlog** for building the boiler-plate.
Each story is the *smallest logical unit* that still delivers a sliver of value and can be picked up by an AI agent or an individual developer.

---

## Legend & Conventions

| Field    | Meaning                               |
| -------- | ------------------------------------- |
| **ID**   | `P#-S#` = Phase number – Story number |
| **Pts**  | 1 = ≤4 h, 2 = \~8 h, 3 = \~12 h       |
| **Tags** | phase, epic, feature, component       |
| **Deps** | Story IDs that must be finished first |

> **Mapping**
> *Epic → Feature → Story* hierarchy is reflected in the `tags`.

## How to Read / Use This Backlog

1. **Pick a phase** sequentially; all dependencies are forward-declared.
2. **Assign** stories to AI agents / developers; each is ≤ 12 h.
3. Use **tags** to filter (e.g., `epic:ui-library`).
4. Each completed phase results in a runnable, deployable increment.

Feel free to request **additional phases** (e.g., Notification UI, multi-tenant billing) or deeper task granularity at any time.
